Wiki-Entity-Summarization Toolkit

A high-performance Python framework for loading, querying, benchmarking, and evaluating Knowledge Graph entity summarization algorithms across the WikES and ESBM benchmarks.

$ pip install wikes-toolkit

1. Overview & Theoretical Context

Knowledge Graphs (KGs) such as Wikidata and DBpedia contain millions of entities and billions of relationships. An entity’s description—defined as all triples involving that node in its $t$-hop neighborhood $\Delta_t(v)$—often contains hundreds of edges, overwhelming downstream systems and human interfaces.

Mathematical Formulation of Entity Summarization (ES):

Objective Function
$$S^*(v) = \operatorname*{arg\,max}_{\substack{S(v) \subseteq \Delta_t(v) \\ |S(v)| = k}} \mathrm{score}\big(S(v)\big)$$

The objective is to select an optimal, compact, size-constrained summary $S(v)$ containing exactly $k$ salient triples from the $t$-hop neighborhood $\Delta_t(v)$ that maximizes the informativeness score.

Why WikES? Moving Beyond Prior Benchmarks

Prior benchmarks (e.g., ESBM with 175 entities, FACES with 50 entities, and INFO) rely on small-scale, expensive manual annotations that introduce severe annotator frequency bias. WikES systematically solves this:

Wikipedia Ground Truth

Ground-truth summaries are derived from collaborative Wikipedia abstracts & infoboxes via DistilBERT disambiguation, eliminating manual annotator bias.

2-Hop Topology Preservation

Uses degree-conserving Random Walk sampling to preserve real-world graph topologies, retaining natural density and inter-entity connectivity.

Scale: 100k+ Nodes

Expands evaluation from a trivial hundred nodes to over 248,000 entities and 460,000 directed edges across 4 major domains.

3. Five-Minute Quickstart

Load a WikES graph (e.g., WikESVersions.V1.WikiCinema.SMALL), inspect target entities and ground truths, mark candidate summaries, and compute standard benchmark metrics ($F_1@5$, $F_1@10$, and $\mathrm{MAP}$):

quickstart_wikes.py 
from wikes_toolkit import WikESToolkit, WikESVersions, WikESGraph

# 1. Initialize toolkit (auto-caches data in save_path)
toolkit = WikESToolkit(save_path="./data")

# 2. Load graph with custom human-readable formatters
G = toolkit.load_graph(
    WikESGraph,
    WikESVersions.V1.WikiCinema.SMALL,
    entity_formatter=lambda e: f"Entity({e.wikidata_label})",
    predicate_formatter=lambda p: f"Predicate({p.label})",
    triple_formatter=lambda t: f"({t.subject_entity.wikidata_label})-[{t.predicate.label}]->({t.object_entity.wikidata_label})"
)

# 3. Explore topology and target entities
print(f"Total Entities: {G.total_entities()} | Triples: {G.total_triples()}")
root_nodes = G.root_entities()
sample_target = root_nodes[0]  # e.g., Elvis Presley (Q303)

print(f"Ground-truth summaries for {sample_target}:")
for gt_triple in G.ground_truths(sample_target):
    print(f"  ✔ {gt_triple}")

# 4. Predict / Mark summaries using your summarization algorithm
# (Here marking the first 5 neighbor triples as predicted summary)
predicted_triples = G.neighbors(sample_target)[:5]
G.mark_triples_as_summaries(sample_target, predicted_triples)

# 5. Evaluate benchmark metrics
print("--- Benchmark Evaluation Results ---")
print(f"F1@5   : {G.f1_score(5):.4f}")
print(f"F1@10  : {G.f1_score(10):.4f}")
print(f"F1-Dyn : {G.f1_score():.4f}")
print(f"MAP@5  : {G.map_score(5):.4f}")

4. Dual-Engine Architecture: OOP vs. Pandas

wikes-toolkit provides two execution models to balance deep graph traversal against fast tabular processing:

1. NetworkX OOP Engine

WikESGraph

Underpinned by G._G (NetworkX MultiDiGraph). Returns rich Python objects (Entity, Predicate, Triple).

  • Direct access to graph-theoretic algorithms (Centrality, PageRank, Random Walks).
  • Intuitive formatting lambdas for entity names and triples.
  • Native 2-hop neighborhood traversals.

2. Vectorized Pandas Engine

PandasWikESGraph

Underpinned by memory-mapped Pandas DataFrames (subject, predicate, object columns).

  • Vectorized queries, slicing, and batch-ranking operations.
  • Direct export to CSV via G.export_as_csv() for external ML training.
  • Substantially lower memory overhead on 200k+ edge graphs.

Legacy Support ESBM & ESBM+ Benchmark Integration

The toolkit includes complete backwards-compatible support for ESBM (Entity Summarization Benchmark) v1.2 and ESBM+, including DBpedia and LinkedMDB (LMDB) splits. You can load these via ESBMGraph and evaluate traditional ranked .nt files using mark_nt_file_as_summary().

6. Real-World Use Cases & Cookbooks

Use Case 1

Benchmarking a Custom Centrality / Link Analysis Algorithm

In entity summarization, link-based methods (e.g., PageRank, RELIN, LinkSum) rank candidate triples based on node authority. Here is how you can use the internal NetworkX graph G._G to run PageRank and automatically evaluate against ground truth:

custom_pagerank_eval.py 
import networkx as nx
from wikes_toolkit import WikESToolkit, WikESVersions, WikESGraph

# 1. Load WikES Cinema Graph
toolkit = WikESToolkit(save_path="./data")
G = toolkit.load_graph(WikESGraph, WikESVersions.V1.WikiCinema.SMALL)

# 2. Compute PageRank over the underlying NetworkX MultiDiGraph
print("Computing graph-wide PageRank...")
nx_graph = G._G
scores = nx.pagerank(nx_graph, alpha=0.85, max_iter=100)

# 3. For every target entity, rank neighbor triples by object node importance
for target_entity in G.root_entities():
    candidate_triples = G.neighbors(target_entity)
    if not candidate_triples:
        continue
    
    # Rank triples by the PageRank score of their object entity
    ranked_triples = sorted(
        candidate_triples,
        key=lambda t: scores.get(t.object_entity.identifier, 0.0),
        reverse=True
    )
    
    # Select top-10 candidates as predicted summary
    top_summary = ranked_triples[:10]
    G.mark_triples_as_summaries(target_entity, top_summary)

# 4. Global benchmark evaluation
print(f"Results for PageRank baseline on WikiCinema.SMALL:")
print(f"  F1@5   : {G.f1_score(5):.4f}")
print(f"  F1@10  : {G.f1_score(10):.4f}")
print(f"  MAP@10 : {G.map_score(10):.4f}")
Use Case 2

High-Throughput Vectorized Analysis & CSV Dataset Export

For large-scale GNN preprocessing or LLM fine-tuning pipelines, you can batch iterate through all datasets in a family and export them as tabular CSV edge lists:

export_datasets_pandas.py 
from wikes_toolkit import WikESToolkit, WikESVersions, PandasWikESGraph

toolkit = WikESToolkit(save_path="./data")

# Iterate across all 4 benchmark suites in V1 (LitArt, Cinema, Pro, ProFem)
for dataset_name, G in toolkit.load_all_graphs(PandasWikESGraph, WikESVersions.V1):
    print(f"\nProcessing Suite: {dataset_name}")
    print(f"  Total Entities : {G.total_entities():,}")
    print(f"  Total Triples  : {G.total_triples():,}")
    
    # Fast vectorized predicate distribution via Pandas
    df_triples = G.triples()
    top_predicates = df_triples['predicate'].value_counts().head(3)
    print(f"  Top 3 Predicates:\n{top_predicates}")
    
    # Export graph as normalized CSV files (entities.csv, triples.csv, summaries.csv)
    export_directory = f"./exports/{dataset_name}"
    G.export_as_csv(export_directory)
    print(f"  ✔ Exported cleanly to {export_directory}")
Use Case 3

Comparative Evaluation on ESBM (DBpedia & LMDB)

Run side-by-side evaluation against the historic ESBM benchmark with multi-annotator gold rankings (e.g. gold_top_5 and gold_top_10):

esbm_benchmark_runner.py 
from wikes_toolkit import WikESToolkit, ESBMGraph, ESBMVersions

toolkit = WikESToolkit()
G = toolkit.load_graph(
    ESBMGraph,
    ESBMVersions.Plus.DBPEDIA_FULL,
    entity_formatter=lambda e: e.identifier
)

target = "http://dbpedia.org/resource/Adrian_Griffin"
print(f"Evaluating ESBM Target: {target}")
print(f"Node degree: {G.degree(target)}")

# ESBM provides consensus ground truth annotations across multiple human judges
annotator_0_top5 = G.gold_top_5(target, annotator_index=0)
print(f"Annotator 0 marked {len(annotator_0_top5)} salient triples for top-5")

# Mark candidate triples predicted by your model
model_selected_triples = [
    (target, 'http://dbpedia.org/ontology/birthDate', '1974-07-04'),
    (target, 'http://dbpedia.org/ontology/team', 'http://dbpedia.org/resource/Orlando_Magic'),
    (target, 'http://dbpedia.org/ontology/activeYearsEndYear', '2008')
]
G.mark_triples_as_summaries(target, model_selected_triples)

# Evaluate against all benchmark annotators
print(f"ESBM F1@5: {G.f1_score(5):.4f} | MAP@5: {G.map_score(5):.4f}")
Use Case 4

Neural / LLM-Based Zero-Shot Summarization Pipeline

Build a modern semantic summarization workflow using sentence embeddings to rank relationship labels directly against an entity's Wikipedia-style contextual prompt:

semantic_embedding_summarizer.py 
from wikes_toolkit import WikESToolkit, WikESVersions, WikESGraph
import numpy as np

# Mock semantic embedding function (in practice: SentenceTransformers / Ollama / OpenAI)
def get_embedding(text: str) -> np.ndarray:
    rng = np.random.default_rng(seed=abs(hash(text)) % 100000)
    vec = rng.normal(size=384)
    return vec / np.linalg.norm(vec)

toolkit = WikESToolkit()
G = toolkit.load_graph(WikESGraph, WikESVersions.V1.WikiLitArt.SMALL)

for target in G.root_entities()[:5]:
    target_name = target.wikidata_label
    context_query = f"Key biographical facts, major literary works, and awards of {target_name}"
    query_emb = get_embedding(context_query)
    
    scored_triples = []
    for triple in G.neighbors(target):
        triple_repr = f"{triple.subject_entity.wikidata_label} {triple.predicate.label} {triple.object_entity.wikidata_label}"
        triple_emb = get_embedding(triple_repr)
        sim = float(np.dot(query_emb, triple_emb))
        scored_triples.append((sim, triple))
        
    scored_triples.sort(key=lambda x: x[0], reverse=True)
    top_5 = [item[1] for item in scored_triples[:5]]
    G.mark_triples_as_summaries(target, top_5)

print(f"Semantic Ranker F1@5: {G.f1_score(5):.4f} | MAP@5: {G.map_score(5):.4f}")

8. Comprehensive API Reference

class WikESToolkit(save_path="./data")

Primary entry point responsible for downloading, local caching, and instantiating graph representations.

load_graph(graph_class, dataset_version, entity_formatter=None, predicate_formatter=None, triple_formatter=None)

Loads and parses a single dataset variant. Returns an instance of WikESGraph, PandasWikESGraph, or ESBMGraph.

load_all_graphs(graph_class, version_family)

Generator yielding tuples of (dataset_name, G) for each dataset within a version group (e.g. WikESVersions.V1).

methods Graph Inspection & Evaluation

Method Signature Return Type Description
root_entities() List[Entity] | Series Target entities with ground-truth summaries.
neighbors(entity) List[Triple] | DataFrame All incoming & outgoing triples connected to entity.
ground_truths(entity) List[Triple] | DataFrame Golden summary triples extracted from Wikipedia abstract.
mark_triples_as_summaries(entity, triples) None Stores model-predicted summary candidates for evaluation.
clear_summaries() None Flushes all currently marked predicted summaries.
f1_score(k=None) float Harmonic mean of precision and recall. If $k$ is omitted, dynamic summary length is computed.
map_score(k=None, no_rel=False) float Mean Average Precision for ranked evaluation. no_rel=True evaluates without edge relation matching.
export_as_csv(output_path) None Exports entities, triples, and summaries as normalized CSVs (available on PandasWikESGraph).
